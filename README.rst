DFU library
===========

Summary
-------

Device firmware upgrade

Features
........

  - One upgrade slot

Components
...........

Device and host code for requests such as *get status* and *download* that
implement firmware upgrade with data partition support.

Software version and dependencies
.................................

The CHANGELOG contains information about the current and previous versions.
For a list of direct dependencies, look for DEPENDENT_MODULES in lib_dfu/module_build_info.

.........................
